## ✨ 서비스 소개 / 대상 사용자

**SIMVEX**는 복잡한 기계 부품의 구조를 3D로 시각화하고, 분해/조립 과정을 단계별로 학습할 수 있는 **공학 학습 특화 웹 플랫폼**입니다.

<table>
<tr>
<td width="50%" valign="top">

### 💡 핵심 차별점

| | 특징 |
|:---:|:---|
| 🔧 | **인터랙티브 3D 분해 학습** - 슬라이더로 단계별 분해 과정 시각화 |
| 🤖 | **AI 기반 학습 보조** - 선택한 부품에 대한 맞춤형 AI 답변 |
| 📋 | **통합 학습 관리** - 노트, PDF 리포트, 워크플로우, Notion 동기화 |

</td>
<td width="50%" valign="top">

### 🎯 대상 사용자

| | 대상 | 설명 |
|:---:|:---:|:---|
| 🎓 | **공학계열 대학생** | 기계공학, 항공우주공학, 자동차공학 전공 |
| 🏭 | **기술직 재직자** | 기계 설비 관련 업무 종사자 |
| 🏫 | **교육 기관** | 공학 실습 교육 대학/직업훈련원 |

</td>
</tr>

## 🔍 사용자 및 문제 정의

<div align="center">

### 기존 문제점 vs SIMVEX 솔루션

</div>

| 😫 기존 문제 | 💡 SIMVEX 솔루션 |
|:---|:---|
| 2D 도면만으로는 복잡한 3D 구조 이해가 어려움 | **360° 회전, 줌, 팬** 조작이 가능한 3D 모델 뷰어 |
| 실제 기계 분해 학습은 비용과 안전 문제 존재 | **가상 분해도 슬라이더**로 안전하게 분해 과정 학습 |
| 각 부품의 역할과 재질 정보 파악이 어려움 | 부품 선택 시 **상세 정보 즉시 확인** |
| 학습 내용 정리 및 복습이 번거로움 | **노트 작성, AI 대화, PDF 리포트** 자동 생성 |
| 학습 계획 수립 및 진행 관리가 복잡 | **워크플로우 차트 + Notion 동기화** |

## 🔐 보안 기능

```
┌──────────────────────────────────────────────────────────────────┐
│                       🛡️ Security Layers                        │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐         │
│   │ Rate Limit  │    │   Input     │    │   Token     │         │
│   │   100/min   │ -> │ Validation  │ -> │ Encryption  │         │
│   │  (AI:20/m)  │    │  (Regex)    │    │ (AES-256)   │         │
│   └─────────────┘    └─────────────┘    └─────────────┘         │
│                                                                  │
│   ┌─────────────┐    ┌─────────────┐                            │
│   │  Prompt     │    │   Redis     │                            │
│   │ Injection   │ -> │  Session    │                            │
│   │   Block     │    │   Auth      │                            │
│   └─────────────┘    └─────────────┘                            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

| 보안 레이어 | 설명 |
|:---|:---|
| **Rate Limiting** | API 요청 제한 - 오브젝트: 100회/분, AI: 20회/분 |
| **Token Encryption** | AES-256-GCM으로 Notion 토큰 암호화 저장 |
| **Input Validation** | 정규식 ID 검증, 메시지 길이 제한 (1000자) |
| **Prompt Injection Block** | 시스템 프롬프트 분리로 인젝션 방지 |
| **Session Auth** | Redis 기반 세션 관리, 보안 강화 |
